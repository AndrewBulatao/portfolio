# Portfolio

This is my personal portfolio website showcasing my projects, skills, experience, and interests in software development.

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap
* Node.js
* Express.js
* Google Gemini API
* GitHub Contribution Graph Widget
* Vercel

## Features

* Responsive design
* Project showcase
* Custom styling and layout
* AI-powered Calcifer chatbot
* Dynamic AI-generated responses about my projects and experience
* GitHub contribution graph
* Server-side API for securely communicating with the Gemini API
* Vercel deployment
